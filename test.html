Test: live OSM tiles + our own street labels, full-width layout. Same route-card content as a real printed route sheet (js/printSheets.js), with three changes from this round:
  1. .route-map is a live Leaflet map on CARTO's "Positron" tiles (light, low-detail, built on OpenStreetMap data) instead of the hand-drawn schematic.
  2. Each of the route's own roads gets a label drawn directly on it, rotated to follow the road. This is deliberately not left to the tile provider — CARTO/OSM tiles often don't label short residential roads or cul-de-sacs at all at this zoom (try "The Mews" from the streets list — a tile-only label would likely be missing), whereas we already know every name and its exact geometry from the route data, so we can guarantee it's labelled.
  3. The map now spans the full page width with the rest of the sheet stacked below it, rather than a half-width square next to a text column — makes better use of an A4 page and leaves room for a wider, more legible map.
The route/coordinates are still an approximate stand-in near Blyth, Nottinghamshire, not verified real geometry.

Known wrinkle if this goes further: tiles load asynchronously, so printing immediately on page load can catch the map mid-load with blank/grey tiles — the real generator should wait for each map's load event before enabling print.
