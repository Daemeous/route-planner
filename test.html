Test: live OSM tiles instead of the hand-drawn schematic. This page is the same route-card layout as a real printed route sheet (js/printSheets.js), but .route-map now holds a live Leaflet map on CARTO's "Positron" tiles — a light, low-detail style built on OpenStreetMap data (thin roads, muted colours, only the more important street/place labels) rather than the busy default OSM style. The route and coordinates below are an approximate stand-in near Blyth, Nottinghamshire, not verified real geometry — this is only to judge whether real street names and points of interest around the route make it easier to place yourself, compared to the grey unlabelled lines from the previous fix.

Known wrinkle if this goes further: tiles load asynchronously, so printing (or Save-as-PDF) immediately on page load can catch the map mid-load with blank/grey tiles. This test waits for Leaflet's own load event before it's considered "ready" — worth the same handling in the real print-sheet generator, e.g. only enabling the print button once every route's map has fired that event.
